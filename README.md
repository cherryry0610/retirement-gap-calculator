# 退休你思奇｜退休缺口計算機

繁體中文、港幣退休規劃工具。純 HTML、CSS 及 JavaScript，毋須安裝套件或後端。

## 功能

- 即時計算所需退休資金、預計資產、缺口或盈餘及達標率
- 計算每月額外儲蓄及總儲蓄目標
- 可修改退休前後回報率、通脹及資金緩衝
- 支援手機排版及列印／儲存 PDF
- 財務輸入僅在瀏覽器計算，沒有分析追蹤、資料庫或傳送機制

## 使用

直接開啟 `index.html`，或在本目錄執行 `python3 -m http.server 8000` 後瀏覽 `http://localhost:8000`。

## GitHub Pages 部署

在 repository 的 Settings → Pages，選擇 Deploy from a branch，分支選 main，目錄選 / (root)，然後 Save。完成後以 Pages 顯示的網址為準。

## 計算假設

所有金額均使用港幣。生活費與退休收入輸入為今日幣值，均按同一通脹率增長；退休收入由退休起領取至計劃年齡。現有資產及月底定額儲蓄按退休前回報累積，退休一次過收入為退休當日金額，避免與資產或儲蓄重複。

所需退休本金按逐月月初收支缺口折現，期末本金可用盡，再加指定緩衝。已退休時顯示即時需補足金額。

示例回報與通脹並非保證。未計稅項、投資波動、提款次序風險或有期限／延後領取收入；不構成個人投資建議。
